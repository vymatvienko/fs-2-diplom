# Кинотеатр: Система бронирования билетов

Это система бронирования билетов в кино, разработанная на Laravel и PHP.  Система позволяет пользователям выбирать фильмы, сеансы, места и оплачивать билеты.


## Установка и запуск

### 1. Клонирование репозитория

Клонируйте репозиторий на локальную машину:

git clone https://github.com/your-username/cinema-ticket-booking.git


Замените your-username на ваше имя пользователя GitHub.


### 2. Установка зависимостей

Перейдите в каталог проекта и установите зависимости Composer:

cd cinema-ticket-booking
composer install



### 3. Настройка файла .env

Скопируйте .env.example в .env:

cp .env.example .env


Настройте параметры подключения к базе данных в .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cinema_db
DB_USERNAME=root
DB_PASSWORD=password


Важно:Замените `cinema_db`, `root` и `password` на ваши данные.


### 4. Генерация ключа приложения

```bash
php artisan key:generate
```


### 5. Миграции базы данных

Создайте и запустите миграции:

```bash
php artisan migrate
```


### 6. Заполнение тестовыми данными (опционально)

Для заполнения базы данных тестовыми данными:

```bash
php artisan db:seed
```


### 7. Запуск локального сервера

Запустите локальный сервер:

```bash
php artisan serve
```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`.


### 8. Настройка фронтенда (опционально)

Если используется фронтенд (например, с Laravel Mix):

```bash
npm install
npm run dev
```


## Работа с системой

1. Перейдите на `http://127.0.0.1:8000`.
2. Выберите фильм, сеанс и места.
3. Подтвердите оплату.
4. Получите QR-код для входа.


## Структура проекта

  `app/` - Логика приложения (контроллеры, модели и т.д.).
  `resources/views/` - HTML-шаблоны (Blade).
  `public/` - Публичные файлы (CSS, JS, изображения).
  `routes/` - Маршруты (web.php).
  `database/` - Миграции, сидеры и т.д.


## Разработка и тестирование
