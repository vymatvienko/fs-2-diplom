# Кинотеатр: Система бронирования билетов

Это система бронирования билетов в кино, разработанная на Laravel и PHP.  Система позволяет пользователям выбирать фильмы, сеансы, места и оплачивать билеты.

## ✅ Предварительные требования

Перед установкой убедитесь, что у вас установлены:

- **PHP 8.1+** (рекомендуется последняя версия)
- **Composer** (менеджер зависимостей PHP)
- **MySQL 8.0+**
- **Node.js 18+** и **npm** (если используется фронтенд)
- **Git** (для клонирования репозитория)

### 📌 Проверка установленных версий

Чтобы проверить, что всё установлено, выполните:

- **php -v**        (Должно показать версию PHP 8.1+)
- **composer -V**   (Должно показать версию Composer)
- **mysql** --version**  (Должно показать MySQL 8.0+)
- **node -v**       (Должно показать версию Node.js)
- **npm -v**       (Должно показать версию npm)
- **git --version** (Должно показать версию Git)

## Установка и запуск

### 1. Клонирование репозитория

Клонируйте репозиторий на локальную машину:

git clone https://github.com/vymatvienko/fs-2-diplom.git


### 2. Установка зависимостей

Перейдите в каталог проекта и установите зависимости Composer:

cd cinema-booking
composer install



### 3. Настройка файла .env

Настройте параметры подключения к базе данных в .env:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cinema_db
DB_USERNAME=root
DB_PASSWORD=password


Важно:Замените `cinema_db`, `root` и `password` на ваши данные.


### 4. Генерация ключа приложения

```bash
php artisan key:generate
```


### 5. Миграции базы данных

Создайте и запустите миграции:

```bash
php artisan migrate
```


### 6. Заполнение тестовыми данными (опционально)

Для заполнения базы данных тестовыми данными:

```bash
php artisan db:seed
```


### 7. Запуск локального сервера

Запустите локальный сервер:

```bash
php artisan serve
```

Приложение будет доступно по адресу: `http://127.0.0.1:8000`.


### 8. Настройка фронтенда

```bash
npm install
npm run dev
```


## Работа с системой

1. Перейдите на `http://127.0.0.1:8000`.
2. Выберите фильм, сеанс и места.
3. Забронируйте.
4. Получите QR-код для входа.


## Структура проекта

cinema-booking/
├── app/                 # Логика приложения (контроллеры, модели)
├── bootstrap/           # Файлы начальной загрузки
├── config/              # Конфигурационные файлы
├── database/            # Миграции и сидеры
├── public/              # Публичные файлы (CSS, JS, изображения)
├── resources/views/layout     # Blade-шаблоны
├── routes/              # Файлы маршрутов (web.php, api.php)
├── storage/             # Логи, кэш и временные файлы
├── tests/               # Тесты Laravel
└── .env        # Файл конфигурации окружения


## Разработка

### 📌 Очистка кеша

- php artisan cache:clear
- php artisan config:clear
- php artisan route:clear

### 📌 Запуск миграций заново (если что-то сломалось)
- php artisan migrate:fresh --seed
